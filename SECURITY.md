# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within WirePlant, please report it responsibly rather than opening a public issue.

- **Email**: Send vulnerability reports directly to [engineers@macrodataware.com](mailto:engineers@macrodataware.com).
- **Details**: Please include the crate name, reproducible steps or payload, observed impact, and any mitigation suggestions.
- **Response Timeline**:
  - Initial acknowledgement within 48 hours.
  - Vulnerability confirmation and impact assessment within 5 business days.
  - Coordinated security advisory and release patch published upon fix completion.
